# Advanced Backend Node.js Learning

This repository is a structured learning workspace for mastering Node.js with a strong focus on backend development. It combines conceptual notes, practical code examples, and structured documentation to build a deep understanding of how Node.js works under the hood.

## Purpose
This project is designed for serious learning and continuous growth in backend engineering. The goal is not only to understand syntax, but also to develop a strong foundation in:

- runtime architecture
- asynchronous programming
- event-driven execution
- module systems
- I/O and concurrency models
- server-side application design

## What This Repository Covers
The content here is organized around core Node.js concepts that are essential for advanced backend development:

- V8 engine internals: parser, interpreter, compiler, and garbage collection
- runtime execution behavior and context switching
- client-server architecture
- thread behavior and concurrency models
- Apache vs NGINX architecture
- high I/O vs high CPU processing
- Libuv, handles, requests, and event loop phases
- promises, timers, microtasks, and macrotasks
- modules in Node.js
- package and dependency management with npm

- [demo_1.js](demo_1.js), [demo_2.js](demo_2.js), [demo_3.js](demo_3.js), [demo_4.js](demo_4.js): asynchronous execution and event loop demonstrations

## Learning Approach
This repository is meant for continuous learning and practical understanding. The workflow is simple:

1. Study one concept deeply.
2. Write clear notes in the documentation.
3. Verify the concept through a code example.
4. Review and improve the explanation over time.
5. Keep updating the repository as learning progresses.
